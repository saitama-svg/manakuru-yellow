# マナクル YELLOW — GitHub Pages 公開用ファイル

このフォルダーは「マナクル YELLOW」の公開・アプリインストール用パッケージです。決定したロゴをサイズ違いにし、ブラウザーのタブ・ホーム画面アイコン・PWA設定を追加しています。

## GitHub Pages への公開

1. GitHubでリポジトリ `manakuru-yellow` を作成します。GitHub Freeで利用するなら **Public** を選びます。
2. このフォルダー内の**すべてのファイルと `.nojekyll`** を、リポジトリの一番上（root）へアップロードします。`index.html` がサブフォルダーの中に入らないようにします。
3. リポジトリの **Settings → Pages** を開きます。
4. Source を **Deploy from a branch**、Branch を **main**、Folder を **/(root)** にして Save します。
5. 公開されたURLを開き、画面が正しく表示されることを確認します。通常のURL形式は `https://GitHubのユーザー名.github.io/manakuru-yellow/` です。

## デスクトップにアプリのアイコンを置く

公開されたURLを Microsoft Edge などの対応ブラウザーで開き、ブラウザーのメニューから「アプリとしてインストール」などの項目を選びます。表示される項目はブラウザーによって異なります。インストール後、ブラウザーが対応していればデスクトップのショートカットを作れます。

## 含まれる主なファイル

- `index.html`：アプリ本体（v86 brand/PWA）
- `manifest.webmanifest`：アプリ名・表示形式・アイコンの設定
- `sw.js`：同じサイト内のアプリ本体とアイコンをキャッシュするサービスワーカー
- `icon-192.png` / `icon-512.png`：アプリ用アイコン
- `favicon.ico` / `favicon-32.png` / `favicon-48.png`：ブラウザーのタブ用アイコン
- `apple-touch-icon-180.png`：iPhone/iPad用アイコン

## 注意

- リポジトリと公開サイトは公開状態になります。HTMLソースも一般の人が閲覧できます。パスワードや個人情報を含めないでください。
- 学習データは各ブラウザーのローカル保存であり、利用者同士で自動共有されません。
- ローカルのHTML版から公開サイトへ移行する際は、先にアプリの「全データを保存」でバックアップを作ることをおすすめします。保存先が変わるため、以前のデータが自動で現れないことがあります。
- このパッケージには、今回決定したロゴ画像を変えずにリサイズしたものを使っています。新たな画像生成は行っていません。
- アプリのメイン画面の色設計全体は今回変更せず、アプリ名・ブラウザーアイコン・PWAの色設定を更新しています。
