    📦 データ管理

    問題集・成績・学習履歴・タイムアタック記録を安全に持ち運ぶための機能です。問題集だけを共有する場合と、自分の学習データを全部移行する場合を分けて扱えます。

    このHTMLファイルごとに保存先が分離されています。同じPC・同じブラウザで別のマナクル YELLOWHTMLを開いても、問題・成績などは共有されません。HTMLを別名で保存・移動したり、別のPCへ移したりする場合は「全データを保存」からバックアップを作成してください。ローカルファイル（file://）の保存動作はブラウザによって異なるため、大切なデータは定期的に外部へバックアップしてください。

    🛡️ 自動保存・直前の状態への復元

    問題集・成績などの変更は、このHTML専用のブラウザ保存領域へ自動保存されます。登録欄の未適用の入力も下書き保存します。変更前の状態は直前の1世代だけ自動で保護します。別のPCやブラウザへ移す場合は、上の「全データを保存」も利用してください。

    復元ポイントを確認中

    必要なときに「保存状態を確認」を押すと、ブラウザの保存領域と現在の問題集データを読み戻して確認します。

    問題集を変更する前の状態を自動保存します。

    💾 全データをバックアップ

    すべての問題集と、それぞれの成績・学習履歴・タイムアタック記録を1つのファイルにまとめます。別のPCへ移すときはこちらを使ってください。

    ⚠ 全データの復元を行うと、このブラウザに保存されている現在の問題集・成績・履歴がバックアップ内容で置き換わります。復元前に現在のデータをバックアップしておくことをおすすめします。

    📚 現在の問題集だけ共有

    問題・答え・出題設定だけを書き出します。成績や学習履歴は含みません。友達に問題集を渡すときなどに使えます。

    🛡️ 初期化

    すべての問題集と関連データをこのブラウザから削除します。実行前に確認画面を表示します。

    バックアップはJSONファイルとして保存されます。自動的にオンラインへ送信されることはありません。このページを閉じる前に、必要なバックアップファイルをOneDriveやUSBなどへ保存してください。
    GUIDE / はじめての方へ

    使い方

    マナクル YELLOWは、問題を登録して「見て覚える」「思い出して答える」「苦手な問題を復習する」ための学習ツールです。最初は下の4ステップだけで大丈夫です。詳しい機能は、必要な項目を開いて確認できます。

    1問題を用意自分で作るか、ChatGPTなどで作った文章を使います。
    2問題を登録問題と答えを取り込み、内容を確認して適用します。
    3学習するインプットで覚え、アウトプットでテストします。
    4復習する間違い・弱点・今日の復習に取り組みます。

    まず知っておくと便利なこと

    📚 問題集は「教科書・単元」ごとに

    「問題集」から新しい問題集を作れます。例えば「歴史・明治時代」「英単語」「数学・二次関数」のように分けると、問題や成績、復習予定を整理しやすくなります。

    🔀 インプットとアウトプットを使い分ける

    インプットは答えを見ながら覚える時間、アウトプットは答えを隠して思い出す時間です。上部の切り替えボタンでいつでも移動できます。

    インプット：カード・一覧・問題登録・問題管理アウトプット：ルーレット・今日の復習・成績・タイムアタック・白紙勉強法

    💾 ふだんは自動保存

    問題・成績などは、このHTML専用の保存領域に自動保存されます。ただし、別のHTMLファイルや別のPCには自動で引き継がれません。大切なデータは「データ管理」からバックアップしてください。

    🎯 今日の目標を決める

    アウトプット画面の「今日の目標」では、「今日の復習を完了」「弱点を自信ありで正解」「問題を指定数解く」「自信あり正解を増やす」から選べます。目標を使わず、いつものルーレット学習だけを続けても構いません。

    📝 白紙勉強法（任意）

    「白紙勉強法」では、左側に手掛かりを用意し、右側の白紙に覚えている内容を書き出します。問題集を選んで連携することも、問題集を使わず自由なノートとして使うこともできます。通常の一問一答だけで学習しても構いません。

    🧭 迷ったらこの順番

    問題登録 → カード学習 → ルーレット → 間違いの解き直し → 今日の復習がおすすめです。すぐにテストしたい場合は、登録後に「アウトプット」の「ルーレット」から始めても構いません。

    機能別ガイド

    01問題を登録するChatGPTの文章や表を取り込み、問題集にする
    1. 必要なら「問題集」→「＋ 新しい問題集」で問題集を作り、開きます。
    2. 上部を「インプット」に切り替え、「問題登録」を開きます。
    3. ChatGPTなどで作った問題と答えを「AIで作った問題を貼り付け」に貼り、「自動で整形する」を押します。
    4. 表示された表で問題と答えを確認します。必要なら表の中を直してから「この内容を問題欄に入れる」を押します。
    5. 下の問題欄にも内容が入ったことを確認し、必要なら「操作プレビュー」で表示を試して、最後に「適用する」を押します。

    対応する形式：「Q1. 問題／A1. 答え」「問題 → 答え」、番号付きの一問一答、タブ区切り、表形式など。うまく分かれないときは、下の問題欄に1行につき1セットで「問題［タブ］答え」と入力するか、表計算ソフトの2列をそのまま貼り付けてください。

    大切：「自動で整形する」は、貼り付けた文章を問題と答えに分ける機能です。問題そのものを新しく考えて作るAI機能ではありません。登録できるのは最大150セットです。
    02インプット：見て覚えるカード学習と一覧学習の使い分け

    カード学習：1問ずつ答えを隠して表示します。「答えを見る」で確認し、必要ならヒントも見られます。「← 前へ」「次へ →」で移動し、確認後に「覚えた」または「まだ不安」を記録します。

    一覧学習：問題をまとめて眺めたいときに使います。問題・答えから検索したり、「覚えた／まだ不安／未判定」で絞ったり、すべての答えをまとめて表示・非表示にできます。

    「まだ不安」とした問題は、あとでまとめてアウトプットのテストに回せます。インプットでの自己判定は、通常テストの正答率や正解数には加算されません。

    手書きスペースを開くと、マウス・タッチペン・指などでメモできます。書いた内容は一時的なもので、問題や成績には保存されません。

    キーボード操作を有効にしている場合、カード学習では ← 前へ／→ 次へ／Enter 答えを表示 が使えます。設定は「デザイン設定」で変更できます。
    03アウトプット：ルーレットでテストする答えの表示、自己採点、キーボード操作
    1. 上部を「アウトプット」に切り替え、「ルーレット」を開きます。
    2. 問題が出たら、答えを思い出してからカードをクリック／タップするか Enter で答えを表示します。
    3. 自分の答えと比べ、ボタンかキーボードで判定します。
    A：正解・自信ありD：正解・自信なしS：不正解Enter：答えを表示

    通常のルーレットは、設定した問題を1周の中で重複させずに出題します。1周が終わると結果が表示され、「間違えた問題だけ解き直す」「間違えた問題をカードで確認」「弱点問題を解く」「おまかせ学習」「もう一周する」を選べます。

    「正解・自信なし」も正解として記録されますが、まだ定着していない可能性があるため、弱点や復習候補として優先されます。

    03+白紙勉強法で思い出して書き出す自由なノート、または問題集と連携して何度も復習
    1. メニューの「白紙勉強法」から題名付きノートを作ります。
    2. 左側に解説・キーワード・ヒントを書き、右側の真っ白な紙に覚えている情報を書き出します。
    3. 問題集と連携したい場合は、ノート編集画面の「問題集と連携する」から問題集と全体またはタグを選びます。
    4. 必要なときに答えを表示し、足りなかった内容を再インプットしてから「もう一度思い出す」を押します。

    ノートと過去の挑戦は題名ごとに保存されます。白紙勉強法は任意の学習方法なので、普段の一問一答だけで学習しても構いません。

    04成績・弱点・おまかせ学習苦手を見つけて、今やる問題を自動で選ぶ

    「成績・弱点」では、問題ごとの回答回数、正解（自信あり／なし）、不正解、正答率、最終回答日、学習履歴を確認できます。「未学習だけ解く」や「弱点問題を解く」から、対象を絞って練習できます。

    「おまかせ学習」は、今までの回答結果などをもとに問題を選びます。

    • 弱点克服：苦手な問題を重点的に練習
    • バランス学習：苦手とそれ以外を組み合わせて練習
    • 総復習：広い範囲をもう一度確認

    問題数は10・20・30・50・全問から選べます。おまかせ学習の結果は、通常の成績に記録されます。

    「タイムアタック」は別枠の記録です。通常の成績・弱点判定には影響しません。

    05今日の復習・反復学習・テスト日忘れかけたころに、適切な間隔で復習する

    「今日の復習」は、復習予定の日になった問題を集める機能です。まずは「今日の復習を始める」を押すだけで使えます。通常のルーレットとは別の入口で、今日の復習対象外の問題も通常学習ならいつでも解けます。

    「正解・自信あり」で進むと、復習間隔が1日後 → 3日後 → 7日後 → 14日後 → 30日後 → 60日後と伸びていきます。「正解・自信なし」または不正解の場合は、1日後からやり直します。通常学習で答えた結果も復習予定に反映されます。

    詳しい設定を開くと、テスト日を設定したり、期限を過ぎた問題だけ・未学習の問題から復習したりできます。「反復学習を停止」は自動で復習予定を進める機能を一時停止します。これまでの記録は削除されず、あとで再開できます。

    復習予定は問題集ごとに管理されます。複数の問題集を使うときは、いま開いている問題集名を確認してください。
    06タグ・問題管理・問題集を整理する分野別学習、問題の編集、フォルダ分け

    分野・タグ：問題に「江戸時代」「文化史」「人物」のようなタグを付け、特定の分野だけを通常学習・弱点・今日の復習の対象にできます。複数のタグはカンマ、読点、改行などで区切ります。

    問題管理：問題文・答えの検索、問題の追加・編集・削除、並び替えができます。並び替えだけなら成績は維持されますが、問題文や答えを変更した問題は、それまでの成績を引き継ぎません。

    問題集：問題集を作成・切り替えでき、フォルダ分け、検索、表示条件の絞り込み、並び替え、アーカイブができます。問題集を複製すると問題内容は引き継がれますが、成績は新しく始まります。反復学習は問題集ごとに停止・再開できます。

    07印刷プリントを作る紙で解く、赤シートで隠す、PDFとして保存する

    「印刷」では、現在の問題集を使って、答えを書くプリント、語句・意味を見本にするプリント、小テスト、赤シート用、問題と答えの一覧などを作成できます。

    1. 印刷したい形式を選びます。
    2. 対象の問題、出題方向、用紙の向きなどを設定します。
    3. プレビューで内容を確認してから印刷します。

    印刷ダイアログでプリンターの代わりに「PDFとして保存」を選べば、PDFファイルとして保管できます。印刷向けの詳細設定は必要なときだけ開いてください。

    08タイムアタックに挑戦する時間内に何問解けるか、決めた問題数を何秒で解けるか

    「タイムアタック」には2つのモードがあります。

    • 時間内に何問？：30・60・90・120秒から選び、その時間内にできるだけ多く答えます。
    • 決めた問題数を何秒？：10・20・30・全問から選び、解き終わるまでの時間に挑戦します。

    問題が出たら答えを考え、「答えを見る」を押してから「正解／不正解」で判定します。Aで正解、Sで不正解を入力するキーボード操作も使えます。記録と自己ベストは問題集ごとに保存されますが、通常の成績とは分離されています。

    09学習設定・デザイン・効果音出題方向、文字サイズ、手書き、音量などを自分好みに

    学習設定：出題方向を「言葉 → 意味」「意味 → 言葉」「ランダム」から選び、1回の出題数を10・20・50・すべてから設定します。学習の途中で設定を変えた場合は、ルーレットの「↻ リセット」で新しい設定を反映します。

    デザイン設定：テーマ・アクセント色、正解／不正解の表示の強さ、学習画面の文字サイズ、画面の情報量、ヌーの表示、手書きスペース、インプット中のキーボード操作を調整できます。変更したら「デザイン設定を保存」を押してください。

    効果音：オン／オフと音量を設定でき、正解音とボタン操作音を試聴できます。不正解時は音が鳴りません。音量を0%にすると消音になります。

    手書きスペースへの書き込みは一時的なメモで、問題や成績として保存されません。

    10データを守る・別のPCへ移す・共有する自動保存、バックアップ、URL、共有用HTMLの違い

    自動保存：問題や成績の変更は、このHTML専用のブラウザ保存領域に自動で保存されます。画面の「自動保存」表示も確認できます。別のHTMLファイル・別のブラウザ・別のPCとは保存先が分かれます。

    全データを移行する：「その他」→「データ管理」→「全データを保存」で、問題集・成績・履歴・タイムアタック記録などをJSONファイルにまとめます。移行先では「全データを復元」を使います。復元すると、移行先にあるデータがバックアップの内容に置き換わるため、先に移行先もバックアップしてください。

    問題集だけを渡す：「現在の問題集を保存」は問題・答え・出題設定などを保存し、成績・学習履歴は含めません。問題集を渡したいときに使います。

    URL生成：現在の問題・答え・出題設定を含むURLを作ります。URLを開く側も元のマナクル YELLOWのページにアクセスできる必要があります。長いURLは、送信するサービスによっては扱えない場合があります。

    共有用HTMLを保存：問題セットをHTMLファイルに埋め込みます。ファイルを相手のPCで開いて使えるので、URLを共有しづらい場合やオフラインで使いたい場合に便利です。共有用HTMLを開いた側では、問題は引き継がれますが、成績は新しく始まります。

    注意：大切な学習記録は、定期的に「全データを保存」でバックアップしてください。「全データを復元」は、現在の保存データを置き換える操作です。

    困ったときは

    問題が表示されない：「問題登録」で内容を確認し、「適用する」を押したか、問題集が選択されているかを確認してください。

    別のファイルを開いたら成績がない：ファイルごとに保存場所が分かれています。元のファイルを開くか、バックアップを復元してください。

    変更した出題設定が反映されない：「学習設定」を保存し、ルーレットの「↻ リセット」を押してください。

    不安な問題だけ練習したい：カード学習で「まだ不安」を記録して、その問題だけのテストを開始するか、「成績・弱点」から弱点問題を選んでください。

    URL生成

    現在の問題リストを含むマナクル YELLOWを作成します。生成されたURLを共有できます。
    「共有用HTMLを保存」を使うと、問題・答え・設定をこのHTMLファイルに埋め込みます。保存したHTMLを別のPCで開いても使え、そこからもう一度「共有用HTMLを保存」して更新版を作ることもできます。
